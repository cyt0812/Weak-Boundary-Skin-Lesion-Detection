# ISIC2017 训练集“未见图像 Mask”对照：准备状态

状态（2026-10-18 晚）：**五折训练已完成，21,768 张 OOF Mask 已生成；质量评估和一次 seed 42 的可学习融合分类对照也已完成。** 新旧 Mask 的训练图平均 crop Dice 几乎相同（81.64% vs 81.77%）；在同一 150 张验证集上，新旧 Mask 分类预测 150/150 相同，Macro-F1 均为 85.57%，未超过无 Mask 对照的 86.00%。这些是验证集探索结果，不是新的独立测试结论。详见 `oof_full_image_quality_summary.json`、`oof_crop_quality_summary.json` 和 `../feature_fusion_oof_comparison/seed42/paired_validation_comparison.json`。

## 为什么做

现有分类训练 Mask 由见过这 2,000 张训练原图的 MALUNet 生成，而分类验证 Mask 来自 MALUNet 参数训练时没见过的 150 张图。训练/验证预测 Mask 的完整图平均 Dice 分别为 89.79%/84.79%。这可能造成输入分布差，但逐图检查未证明它是分类无收益的主要原因。因此，OOF 是一个**待验证假设**，不是既定修复。

## 已核对的名单

`fold_assignments.csv` 将 2,000 个分类训练 ISIC ID 按三类标签分层后分成 5 折，每折 400 张，五折无重复；分割训练图像、分割真值和分类训练图像 ID 完全对应。官方 150 张验证图与这 2,000 张无 ID 重叠。分类训练实际有 **21,768 个 crop**：痣每图 9 个，黑色素瘤和脂溢性角化病每图 15 个；生成 Mask 时必须按 `image_id` 选模型，不能按 crop 文件数切分。逐折数量和类别见 `fold_audit.json`。

## 如果启动，预先固定的比较方法

1. 对每个折，只用其余 1,600 张原图/分割标签训练 MALUNet。该折 400 张既不用于模型参数训练，也不用于其 checkpoint 选择。现有第 0 折运行器默认干跑，并会拒绝已有输出目录，保护旧权重。
2. 用各折对应的模型仅为本折 400 张分类训练图的全部 crop 生成预测 Mask，合并成新的 21,768-crop OOF 训练 Mask 目录。验证集仍使用现有预测 Mask；不得改用人工真值 Mask。记录每折 held-out Dice 和分类 crop Dice，检查质量是否接近原验证集。
3. 用同样的分类架构、训练设置和随机种子比较现有 Mask 训练方案与 OOF Mask 训练方案；保留相同架构、相同数据的无 Mask 对照。至少重复随机种子，分别报告 Macro-F1、黑色素瘤召回、Accuracy 和不确定性，不只挑一个最佳数字。
4. 150 张验证集已被多次用于选权重与探索，任何继续在它上面调出来的提升都只能称探索性结果。官方 600 张测试集已有已知成绩，不能反复用来挑方案。若报告最终增益，需要独立或预先固定的评估协议。

## 计算和空间

原有 2,000 图、300 轮 MALUNet 用时约 2 小时 14 分。五折各 1,600 图、暂定最多 105 轮，按图像数和轮数粗估，**仅分割训练约 3 小时**，实际时间会因验证、I/O、GPU 负载而变；随后还需要预测 Mask 和分类训练。105 轮来自现有最佳 epoch，是事前固定的资源控制，并不保证五折质量足够。2026-10-18 检查时 D 盘约有 **7.9 GiB** 空闲；脚本读取现有图片，不复制数据，但运行前仍需再次确认空间和输出位置。

`run_oof_malunet_fold.py` 与 `generate_oof_classification_masks.py` 已完成五折训练和 Mask 生成，checkpoint/输入名单检查通过。新目录与旧权重隔离。`train_oof_feature_fusion_comparison.py` 已在质量检查后完成一次 seed 42 的 OOF Mask 分类实验；没有再次用 600 张官方测试图筛选模型。训练/生成进程均已结束，历史记录在 `run_logs/`。

限制：目前只验证原始图像 ID 分离；本地名单没有病灶级 ID，不能据此声称病灶级完全独立。分类验证集也被用于先前模型选择，后续验证数据不是新的独立证据。
